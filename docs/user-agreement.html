开发者提供客户端及 Mac 网关软件，不提供云端计算或模型后端。您需要在自己的 Mac 上安装或取得有权使用的远码网关，并自行准备兼容的 Codex 或模型服务账号、设备、网络与其他运行条件。客户端默认通过局域网直接连接 Mac 网关；手机与 Mac 应处于可互通的局域网，用户在 Mac 上通过 npm 安装并初始化网关，生成配对二维码后使用手机扫码连接。Mac 和网关需保持运行，离开可互通的局域网后无法继续直连。Mac 上的模型服务仍可能按您选择的配置访问网络，不表示模型离线运行。网关搭建方式见 远码安装与扫码连接说明。
