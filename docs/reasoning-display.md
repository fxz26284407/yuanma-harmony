# 三端思考内容与显示设置

按用户要求，原生有可返回思考数据的后端统一适配。设置增加“显示思考内容”，默认关闭；开启后才显示思考卡片，卡片默认收起，点击展开正文及全文。偏好存入已有 displaySettings，仅影响本机展示，三智能体共用，不修改模型思考档位、桌面执行策略或配对身份。

## 返回范围

| 后端 | 原生来源 | 实现与验证 |
| --- | --- | --- |
| Codex | reasoning.summary/content，summaryTextDelta/textDelta 及 item started/completed | 历史、全文和实时映射已接；真实现存会话读到 5 条非空思考摘要，正文与全文一致。本机样本 content 为空，不把摘要宣称为完整内部思考 |
| DeepSeek Harness | assistant/message.content 的 reasoning.text；reasoning-delta、block-end.reasoning；恢复快照的 reasoning-chunks | 已接思考块、实时更新、恢复和按块全文读取。两个真实会话分别读到 10/23 条思考，截断内容全文一致。实时消息结构已对照已安装第一方 SDK，未另起 Agent 或模型调用 |
| Antigravity | StreamAgentStateUpdates 的 plannerResponse.thinking 和既有 brain 历史 | 延续已接持续订阅与历史/全文，显示开关统一生效；真实流式、多选与追加证据见后文 |

只映射各原生公开返回的文本，不解密、拼造或展示 replay 签名、加密载荷。空思考不生成假卡片；工具与助手正文保持原角色。关闭开关时隐藏思考卡片，并把来自思考的运行标题降为通用状态/当前工具状态。

## 代码与边界

- Codex：mobile-history 的 reasoningText 组合原生字符串数组；同一内容不重复展示。执行摘要标记 reasoning，历史和全文不再过滤非空思考。Progress 按 summaryIndex/contentIndex 更新，分开累积摘要和内容，保持原生条目 ID 和终态；实时仅保留有界预览，全文从原生历史读取。
- DeepSeek：历史思考按事件 seq + 内容块 index 独立编号，正文仍只由 text 块构成；工具图片不挂到思考卡。实时思考与正文分别保存，恢复同时处理 text-chunks/reasoning-chunks，结束后以持久事件为准。每块实时最多保留末尾 16000 字符并标记截断；尚未持久化的临时预览不提供无效的全文按钮，完整事件到达后可读全文。
- 手机：复用既有显示设置写入队列与本机身份存储，不增加独立设置文件；旧安装缺少 showReasoning 时为关闭。外观、减少透明度、减少动态效果保存时保留该偏好。三端共用 execution.kind=reasoning 与既有 Markdown/折叠/全文入口。
- 未生成、扩充或上传测试文件、夹具或自检函数；编译与真实会话读取不依赖新增项目测试。仅在用户明确指定的既有 Antigravity 会话中执行本轮对话验证，不新建会话。

### 当前执行状态与思考正文分开（2026-11-05）

- “显示思考内容”仅控制思考卡及正文，不关闭当前执行状态。存在当前轮次、运行/等待/待处理且用户可见的工具或思考卡时，不重复显示底部状态行；无可见活动卡片时，使用“正在思考…”“正在生成回复…”或“等待操作…”兜底。空闲时清除，切换会话和断连时清理旧标题；原生状态未知时明确显示待确认，不冒充正在执行。
- Antigravity 通用工具使用原生 toolCall.name 和 result.stepRenderInfo 的文件 URI 映射编辑/读取/写入/命令等状态，标题只取文件名，不读取文件内容。截图对应的文件在真实原生步骤中已有编辑元数据，不再只标“执行记录”。
- view 仅携带当前活动轮次的运行、等待和待处理进度，实时预览限制为 64 KiB；已完成及更早记录仍由既有历史分页和全文读取提供。加密响应仍保持 256 KiB 上限。
- 300ms 活动 view 刷新与原先通用每分钟 60 次限流不匹配。现仅 GET /threads/:id/view 使用独立每分钟 240 次额度，其他操作和认证检查保持原有路径；该额度覆盖 300ms 刷新，仍有边界。
